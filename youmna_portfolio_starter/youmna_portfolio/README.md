# Youmna Swilm — AI Engineering Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation interaction

## Before publishing
1. Search `Youmna Swilm` and confirm the name is displayed as you want.
2. Replace the generic GitHub and LinkedIn links in the Contact section with your real profile URLs.
3. Replace `your.email@example.com` with the email address you want recruiters to use.
4. Add real project repository/demo links when they are ready. Do not claim metrics or results you have not measured.

## Publish with GitHub Pages (free)
1. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root (not inside another folder).
3. In the repository, open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save if that option appears.
5. Wait a few minutes, then visit `https://YOUR-GITHUB-USERNAME.github.io`.

## Local preview
Open `index.html` in a browser. For a closer development workflow, use VS Code with the Live Server extension.

## Notes
The visual artwork on the project cards is CSS/SVG decoration, not screenshots from the actual applications. The disease-prediction project is described as educational and not for medical diagnosis.
